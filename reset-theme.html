Quick Actions:

Manual Instructions:

  1. Open browser Developer Tools (F12)
  2. Go to Console tab
  3. Type: localStorage.setItem('hrms-theme', 'meridian')
  4. Press Enter
  5. Refresh the page (F5)

Troubleshooting:

If page shows black/dark:

  • You may have Dark theme enabled accidentally
  • Click "Reset to Meridian" button above
  • Or clear browser cache (Ctrl+Shift+Delete)

If CSS doesn't load:

  • Check browser console (F12) for errors
  • Make sure Flask server is running
  • Try hard refresh (Ctrl+F5)
