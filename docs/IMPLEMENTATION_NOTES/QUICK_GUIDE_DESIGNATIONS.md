# 🎯 Quick Guide: Create Designations in Settings

## ⚡ 3-Minute Setup

### **Step 1: Login** (30 seconds)
```
URL: http://127.0.0.1:5000
Email: ama.mensah@meridian.gh
Password: Admin@123
```

### **Step 2: Open Settings** (10 seconds)
- Click the **⚙️ Settings icon** in the top-right corner

### **Step 3: Go to Organization Setup** (10 seconds)
- Click the **"Organization Setup"** tab
- It's between "Notifications" and "Company & Defaults"

### **Step 4: Add a Designation** (30 seconds)
1. Click **"+ Add Designation"** button
2. Fill in the form:
   ```
   Title: Senior Developer
   Department: Engineering
   Level: 4
   ```
3. Click **"Create"**
4. ✅ **Done!**

### **Step 5: Verify It Works** (30 seconds)
1. Go to **Employees** (sidebar)
2. Click **"+ Add Employee"**
3. Look at the "Designation / Job Title" dropdown
4. ✅ Your new "Senior Developer" is there!

## 🎨 Form Fields Explained

### **Title** (Required)
- The job title name
- Examples: "Software Engineer", "HR Manager", "CEO"

### **Department** (Optional)
- Which department this title belongs to
- Select from existing departments
- Can be left blank for cross-department roles

### **Level** (Optional)
- Organizational hierarchy level (1-10)
- 1 = Entry level
- 5 = Manager
- 10 = Executive
- Used for reporting structure and permissions

## 🔍 Troubleshooting

### **Problem: Can't see "Organization Setup" tab**
**Solution:** You must be logged in as **Super Admin**

### **Problem: Add button doesn't work**
**Solution:** 
1. Open browser console (F12)
2. Refresh the page (Ctrl+R)
3. Try again

### **Problem: Changes don't appear**
**Solution:** Refresh the settings page
